# Blank application foundation

The public website intentionally renders an empty page. There are no active product, dashboard, form, payment, or scheduled-job routes.

Historical Supabase migrations and production data are preserved. Reusable Supabase, email, Telegram, Airtable, and Paystack clients remain in `src/lib`. Hosting, domain, environment-variable, and repository configuration remain available for a new product.

Run `npm ci` and `npm run dev` to start from this blank foundation.
